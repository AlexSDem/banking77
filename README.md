# Классификация банковских обращений на BANKING77

Сравнение словных, символьных и объединённых TF-IDF-признаков для определения темы обращения клиента. Во всех трёх вариантах используется LinearSVC с одинаковыми параметрами. Основной вопрос: насколько полезны символьные признаки при разном количестве обучающих примеров?

Датасет — BANKING77: 77 категорий, 10 003 примера в исходном train и 3 080 в test. Для экспериментов достаточно CPU.

## Результаты

После удаления четырёх дубликатов исходный train разделён на training pool (7 999 строк) и validation (2 000 строк). Ниже результаты обучения на всём training pool и оценки на официальном test.

| Признаки | Accuracy | Macro-F1 |
|---|---:|---:|
| Word TF-IDF | 88.12% | 88.12% |
| Character TF-IDF | 89.90% | 89.87% |
| Word + character TF-IDF | **90.91%** | **90.92%** |

Объединение признаков даёт +2.79 п.п. accuracy относительно словной модели. Парный bootstrap по тестовым примерам: 95% интервал разницы [2.08; 3.54] п.п. Он не учитывает вариативность обучения.

Дополнительно проведены эксперименты с ограничением до 10, 30 и 60 примеров на категорию, по три seed: 42, 43, 44. Фактические размеры выборок — 770, 2 308 и 4 537 строк: некоторые категории меньше установленного ограничения. Подробные результаты находятся в `results/summary.csv`, измерения отдельных запусков — в `results/metrics.csv`.

## Запуск

Рекомендуемая версия Python — 3.12.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 python src/experiment.py
```

В Windows окружение активируется командой `.venv\Scripts\activate`. Эксперимент можно запустить через `python src/experiment.py`.

Для запуска в Google Colab откройте `Colab_Banking77.ipynb`. Notebook подготавливает файлы проекта, устанавливает зависимости и выполняет те же эксперименты. GPU не требуется.

Быстрая проверка с одним seed:

```bash
python src/experiment.py --quick
```

Этот режим сохраняет результаты отдельно, в `results_quick`, и не меняет основной отчёт.

## Метод и разбиение данных

- Словная ветка: униграммы и биграммы, до 50 000 признаков.
- Символьная ветка: `char_wb`, n-граммы длины 3–5, до 80 000 признаков.
- Обе ветки используют sublinear TF, сглаженный IDF и L2-нормализацию. После объединения вектор нормализуется повторно.
- Классификатор: LinearSVC, `C=1`, `max_iter=5000`, `tol=1e-4`.

Дубликаты определяются по тексту после приведения к нижнему регистру и удаления лишних пробелов. Очистка выполняется только на train, затем выделяется 20% для validation (`random_state=2026`). Словарь и IDF обучаются заново на каждом обучающем подмножестве. Все модели в одном режиме получают одинаковые строки.

Параметры зафиксированы до экспериментов; поиск гиперпараметров не проводился. Validation используется для диагностики. Важно учитывать, что эти 2 000 размеченных примеров идут сверх указанного ограничения на fitting-выборку.

Между очищенным исходным train и test найдено семь совпадающих нормализованных текстов. Основные результаты рассчитаны на неизменённом official test. При исключении этих семи строк accuracy объединённой модели составляет 90.89% на 3 073 примерах.

## Ограничения

Эксперименты ограничены одним англоязычным датасетом. Для режима training pool выполнен один запуск. Время обучения измерено на серверном CPU; в Colab оно может отличаться.

Нейросетевые результаты в отчёте взяты из Casanueva et al. (2020): BERT-TUNED — 93.66%, USE+ConveRT — 93.36% на полном official train. Эти модели здесь не воспроизводились. Их протокол и объём обучения отличаются от нашего, поэтому значения приведены как ориентир, а не как прямое сравнение при одинаковых условиях.
